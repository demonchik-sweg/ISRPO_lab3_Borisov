## 1. Назначение

Расширение для VS Code, которое оценивает объём оперативной памяти, необходимый C++ программе, **не запуская** её. Анализ выполняется статически — по тексту исходного файла.

**Область применения:** олимпиадное программирование — проверка, укладывается ли решение в лимит памяти (например, 256 МБ), до отправки на проверку.

## 2. Функциональные требования

### 2.1. Анализ статических массивов

Расширение должно находить в активном файле `.cpp` или `.c` объявления вида:

- **Одномерные массивы:** `int a[1000];`
- **Многомерные массивы:** `long long dp[500][500];`
- **Списки через запятую:** `int a[100], b[200];`
- **С выражениями в размере:** `int a[n];`, `int a[n * 2 + 1];`

### 2.2. Анализ векторов

Расширение должно находить объявления `std::vector`:

- **Одномерные:** `vector<int> v(n);`
- **С инициализацией:** `vector<int> v(n, 0);`
- **Многомерные:** `vector<vector<int>> s(n, vector<int>(n));`
- **Трёхмерные:** `vector<vector<vector<int>>> a(n, vector<vector<int>>(m, vector<int>(k)));`
- **Векторы пар:** `vector<pair<int, int>> edges(m);`

Для `vector<T>` учитывается **только память под данные**, без заголовка (24 байта).

### 2.3. Анализ пар

Расширение должно находить `std::pair`:

- **Одиночные:** `pair<int, int> p;`
- **Массивы пар:** `pair<int, int> a[100];`
- **Вложенные:** `pair<long long, pair<int, int>> p;`

Размер `pair<T1, T2>` = `sizeof(T1) + sizeof(T2)`.

### 2.4. Аннотации алгоритмов

Для алгоритмов, использующих **скрытые структуры** (`queue`, `priority_queue`), размер которых определяется в рантайме, пользователь пишет **специальный комментарий-аннотацию**:

**Поддерживаемые алгоритмы:**

| Алгоритм | Структура | Накладные расходы |
|---|---|---|
| `BFS` | `queue<int>` | 80 байт |
| `DIJKSTRA` | `priority_queue<pair<long long, int>>` | 24 байта |
| `MST` | `priority_queue<Edge>` (Прим) | 24 байта |

**Примеры использования:**

```cpp
///BFS n 1 int                          // queue<int> на n элементов
///DIJKSTRA m 2 long long, int          // pq<pair<long long, int>> на m
///MST m 3 int, int, long long          // pq<Edge> на m
///DIJKSTRA m 1 pair<int,int>           // pq<pair<int, int>> на m
```
