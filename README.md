# Memory Size

Расширение для VS Code, которое оценивает объём памяти, занимаемый структурами данных в C++ файле.

**Автор:** [Борисов Дмитрий Дмитриевич], *группа* [M101]

---

## Возможности

- **Статические массивы** — любой размерности: `int a[1000]`, `long long dp[500][500]`
- **Списки через запятую** — `int a[100], b[200];`
- **Векторы** — любой размерности: `vector<int> v(n)`, `vector<vector<int>> s(n, vector<int>(n))`
- **Пары** — `pair<int, int> p`, `pair<long long, int> a[100]`
- **Аннотации алгоритмов** — указывают объём памяти для скрытых структур (queue, priority_queue) через комментарии вида `///ALGO`

Результат выводится в **статус-бар** внизу окна VS Code.
